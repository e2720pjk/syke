5 / Release 前兩個 review flags

SMALL, ACTIONABLE FOLLOW-UPS

P2 · package version enforcement

ensure_pi_binary() 把 missing/invalid package.json 視為 current。若「一定要 0.84.1」是硬需求，應改為只有 exact 0.84.1 才跳過 reinstall，並調整既有 fixture。

P2 · custom replay exclusion

_pi_excluded_paths(home=...) 在傳入 explicit home 時不讀 SYKE_WORKSPACE_ROOT/SYKE_PI_AGENT_DIR override。若 replay/custom workspace 會與 home 分離，應補測試並統一排除路徑。
